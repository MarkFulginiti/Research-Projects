## Research Projects

This repository contains self-contained research projects focused on causal inference, statistical modeling, machine learning, and simulation-based evaluation of estimator behavior. Each project lives in its own folder with a dedicated analysis, supporting documentation, and README.

These projects were developed through coursework in the Johns Hopkins University Applied and Computational Mathematics program and are intended to demonstrate research-level modeling, simulation design, reproducible programming, and methodological reasoning.

### Projects

- **Joint Longitudinal–Survival Modeling**  
  Likelihood derivation and simulation-based evaluation of shared-parameter joint models linking longitudinal processes to time-to-event outcomes. Emphasis on principled likelihood construction, internal time-dependent covariates, and comparison of joint-likelihood and two-stage estimators.

- **Fuzzy Regression Discontinuity Design**  
  Simulation-based examination of fuzzy regression discontinuity estimators, with emphasis on weak compliance, finite-sample instability, and robust inference. The project highlights near-zero denominator behavior, variance inflation under weak identification, and best-practice inference using bias-corrected methods.

- **International Stroke Trial Machine-Learning Pipeline**  
  Comparative prediction of six-month mortality, dependency, and recovery after acute ischemic stroke. Six model classes are evaluated using leakage-resistant preprocessing, cross-validation, hyperparameter tuning, held-out testing, calibration assessment, and model interpretation. The analysis emphasizes that outcome difficulty mattered more than algorithm complexity and that predictive performance does not establish causation.
